# lohithlalesh.com

Static site. Everything lives in `site/`.

- Cloudflare Pages runs `npm run build`, which copies `site/` to `dist/`.
- Preview locally: open `site/` with any static server, e.g. `npx serve site`.
- Hero illustrations generated with Higgsfield; line figures from [hairline](https://github.com/lucasmarkes/hairline) (MIT, vendored in `site/assets/js/`).
